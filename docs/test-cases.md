# Тест-кейсы и результаты проверки

Проверка соответствия `docs/TZ.md`. Каждый кейс автоматизирован; функция-тест указана в последнем столбце
(файл определяется префиксом: `test_geometry`, `test_io`, `test_backup`, `test_cli`).

**Запуск:** `python -m pytest -v` или `python -m unittest discover -s tests -v` (из корня проекта, `PYTHONPATH=src` для unittest).
**Покрытие:** `python -m pytest --cov=polygon_tool --cov-report=term-missing`.
